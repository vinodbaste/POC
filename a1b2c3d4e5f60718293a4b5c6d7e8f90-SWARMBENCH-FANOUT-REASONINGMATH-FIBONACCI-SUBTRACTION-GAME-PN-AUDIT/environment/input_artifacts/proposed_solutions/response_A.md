The Fibonacci subtraction game has a simple repeating structure. Since the moves include 1, 2, 3, 5, 8, etc., the losing positions repeat every 4.

So the P-positions are exactly:

[
0,4,8,12,16,\dots,100
]

Thus the 101-character string is:

```text
PNNNPNNNPNNNPNNNPNNNPNNNPNNNPNNNPNNNPNNNPNNNPNNNPNNNPNNNPNNNPNNNPNNNPNNNPNNNPNNNPNNNPNNNPNNNPNNNPNNNPNNNP
```
