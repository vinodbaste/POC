# Provenance for released model responses

The eight files in `proposed_solutions/` (`response_A.md` through `response_H.md`) are real, unedited responses produced by weak open-weight or fast-tier language models when asked to solve the Fibonacci Subtraction Game P/N classification problem stated in `problem.md`.

Each response was collected verbatim from the model's output. No content was edited, summarized, or normalized. Whitespace, formatting, and partial reasoning chains are preserved as the model produced them.

The auditor does NOT need to use the provenance metadata to label any response; the audit must rely solely on the response text under `proposed_solutions/`.
