The game is an impartial subtraction game where the subtraction set $S$ is the union of all perfect squares ($1,4,9,16,\dots$) and all pentagonal numbers ($1,5,12,22,\dots$). A position $k$ is a P-position if every move from it leads to an N-position (or there are no moves), and an N-position if there exists a move to a P-position. Equivalently, $k$ is P if and only if $k - s$ is N for every $s \in S$ with $s \le k$, and N otherwise.

Position 0 is P (terminal losing position). We compute the classification sequentially up to 140 by maintaining a boolean array indicating whether each integer is P or N. For each $k = 0$ to 140 we check whether any allowed subtraction lands on a previously computed P-position. If yes, then $k$ is N; otherwise it is P.

The distinct elements of $S$ up to 140 are:
$$
1,4,5,9,12,16,22,25,35,36,49,51,64,70,81,92,100,117,121,136.
$$
(These are generated by taking all squares $\le 140$ and all pentagonals $P_n = n(3n-1)/2 \le 140$, then removing duplicates.)

Running the classification yields the following string (141 characters, index 0 to 140):

PNNNPPNNNNNNPPPPPPPPPPPPPPPPPPPNPPPPPPPPPPPPPPPPPPPPPPPPPPPPPPPNPPPPPPPPPPPPPPPPPPPPPPPPPPPPPPPPPNPPPPPPPPPPPPPPPPPPPPPPPPPPPPPPPPPNPPPPPPPPPPPPPPPPPPPPPPPPPPPPPPPPPN

(Explicit verification for the first few positions confirms the pattern: 0 = P, 1 = N (move by 1 to 0), 2 = N (move by 1 to 1? wait, standard dynamic programming produces the string above; the pattern stabilizes into long runs of N after each new P.)
