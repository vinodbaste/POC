# Proof Validity Rubric

Audit each proof attempt as if you were reviewing an olympiad solution draft.

- Mark `correct` only if the candidate solution establishes the stated result with no material logical error.
- Minor omissions or terseness are acceptable only when the missing detail is routine and does not change the core argument.
- Mark `incorrect` if there is a false claim, an unsupported transition, a skipped critical case, or a gap that breaks the argument.
- For incorrect proofs, identify the earliest material issue in one short sentence.
- Do not list every downstream mistake. Report the first point where the proof stops being reliable.
- For correct proofs, set `first_material_issue_summary` to `none`.
