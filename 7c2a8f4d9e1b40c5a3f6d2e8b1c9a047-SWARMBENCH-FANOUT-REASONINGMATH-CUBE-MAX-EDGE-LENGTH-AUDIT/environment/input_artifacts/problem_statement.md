# Cube and Plane — Largest Edge Length Squared

## Subject: Geometry

## Problem

Suppose the distances from the eight vertices of a cube to a certain plane are $0$, $1$, $2$, $3$, $4$, $5$, $6$, $7$ respectively. Among all cubes consistent with this configuration of vertex-to-plane distances, let $S$ denote the set of possible edge lengths. Find the largest possible value of $s^2$ over $s \in S$.
