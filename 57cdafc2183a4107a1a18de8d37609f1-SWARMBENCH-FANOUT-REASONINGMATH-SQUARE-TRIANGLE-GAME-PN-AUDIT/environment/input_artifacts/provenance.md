# Input Provenance

The files in `/input_artifacts/proposed_solutions/response_A.md` through `response_H.md` are real, unedited model outputs collected from public chat interfaces of small and mid-sized reasoning and instruction-tuned models. They were generated by feeding the problem statement in `/input_artifacts/problem.md` (verbatim) to each model and saving the raw output without modification.

The responses are intentionally heterogeneous: long chain-of-thought traces, contradictory intermediate claims, hand-wavy aggregate arguments, off-by-one classification strings, partial enumeration, and incorrect final classification strings all appear. They are NOT answer keys and they do NOT contain the gold classification string or the oracle's failure-reason labels.

The professional task being modeled is real-world post-hoc audit of weak-model game-theory outputs: independently solving the underlying Sprague-Grundy classification problem, then reading each shipped model response and identifying its concrete mathematical reasoning failures from a controlled vocabulary.
