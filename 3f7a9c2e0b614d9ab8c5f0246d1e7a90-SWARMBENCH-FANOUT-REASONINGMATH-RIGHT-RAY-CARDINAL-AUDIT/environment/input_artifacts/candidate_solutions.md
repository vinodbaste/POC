# Candidate Solution Audit Packet

## Original Problem

Let <R,sigma> denote the real numbers equipped with the upper order topology, that is the topology generated by basic open sets of the form O_r = {t in R : r < t} for r in R.

Say that a subset X subseteq R has property N if the cardinality of the set of y in R such that y is an omega-accumulation point of X is less than the cardinality of the set of z in R such that z is a limit point of X.

Suppose 2^omega = omega_3. Let W denote the set of cardinals kappa for which there exists X subseteq R of cardinality kappa with property N.

What is the cardinality of the set of infinite cardinals less than sup(W)?

---

## Response A

1. First, note that if X is a nonempty finite set of reals X={x_0, ..., x_n} ordered in increasing order, then every r < x_n is a limit point of X. This is because every basic open set O_{r'} containing r must be such that r'<r <= x_n, so that x_n in O_{r'} and x_n != r.

2. Furthermore, in this case |X|<omega so there cannot be any omega-accumulation point of X in R, as trivially no open set can contain omega-many points of X.

3. Therefore, if 0<|X|<omega the cardinality of the set of limit points of X is 2^omega=omega_3 while the cardinality of the set of omega-accumulation points of X is 0. So all such X have property N.

4. Next, let X = {0, -1, -2, ...} subseteq R comprise the non-positive integers. As above, every r<0 is a limit point of X and there are omega_3-many such r.

5. Moreover, |O_r cap X|<omega for every r in R, so there do not exist any omega-accumulation points of X. Thus, X = {0, -1, -2, ...} has property N and |X|=omega.

6. Next, let X subseteq R with |X| >= omega_1. Note that R = union_{n in N} (R cap [-n,n]) where N = {0,1,2,3,...} denotes the natural numbers and [-n,n] denotes the set of reals in the closed interval from -n to n.

7. Because X=union_{n in N} (X cap [-n,n]) is a countable union and the cofinality of omega_1 is uncountable, as |X| >= omega_1, there exists some N in omega such that |X cap [-N,N]| >= omega_1.

8. This implies that for every r <= -N, |O_r cap X| >= omega_1. That is, r is an omega-accumulation point of X. The cardinality of the set of such r is 2^omega=omega_3, so X cannot possibly have property N.

9. To summarize, for X subseteq R, if 0<|X|<omega then necessarily X has property N, there exists X such that |X|=omega with property N, and if |X| >= omega_1, X cannot have property N.

10. Therefore, sup(W) = sup((omega \ {0}) union {omega})=omega.

11. There are no infinite cardinals less than omega. That is, the cardinality of the set of infinite cardinals less than sup(W) is the cardinality of emptyset, which is 0, our final answer.

## Response B

We are given a topological space <R,sigma>, where sigma is the upper order topology on R. This topology is generated by the basic open sets O_r=(r,infty).

A point z is a limit point of X iff every neighborhood O_r with r<z intersects X in a point different from z. A point y is an omega-accumulation point of X iff every O_r with r<y contains infinitely many points of X.

Let us construct a large example. Let A subseteq R have cardinality omega_2. For each a in A, pick a sequence x_{a,n} approaching a from the right. For each b in R\A, pick one point y_b>b. Let
X = {x_{a,n}: a in A, n in omega} union {y_b: b in R\A}.

Then every real is a limit point of X. The omega-accumulation points are only the points of A, because only those have countably many points approaching them. Therefore the set of limit points has cardinality omega_3 and the set of omega-accumulation points has cardinality omega_2. Thus X has property N and |X|=omega_3.

Therefore omega_3 is in W, so sup(W)=omega_3. The infinite cardinals below omega_3 are omega, omega_1, and omega_2. Hence the answer is 3.

## Response C

Let T be the upper order topology on R. The open sets are emptyset, R, and all intervals of the form (r,infty).

A point x in R is a limit point of X if every open set containing x also contains a point of X different from x. Since the open sets containing x are of the form (r,infty) with r<x, this means:
x in L(X) iff for all r<x, (r,infty) cap (X\{x}) is nonempty.

A point y in R is an omega-accumulation point of X if every open set containing y contains infinitely many points of X:
y in A(X) iff for all r<y, |(r,infty) cap X| >= aleph_0.

If X is a finite set, then L(X)=emptyset and A(X)=emptyset. In this case, property N is not satisfied since 0<0 is false. Therefore X must be infinite for property N to be potentially satisfied.

For any infinite set X subseteq R, |L(X)|=2^aleph_0. Also A(X) is an initial segment of R, and if it is nonempty then its cardinality is 2^aleph_0. Thus property N requires A(X)=emptyset.

An infinite set X has A(X)=emptyset exactly when it is unbounded below, bounded above, and countable. For example, X={..., -3, -2, -1} has no omega-accumulation points and has continuum many limit points.

Thus W={aleph_0}. Hence sup(W)=aleph_0. There are no infinite cardinals less than aleph_0, so the answer is 0.

## Response D

Answer: 3.

On R the basic open sets are O_r={t in R:r<t}. A point z is a limit point of X iff for every r<z there is x in X\{z} with x>r. A point y is an omega-accumulation point of X iff for every r<y the set X cap O_r is infinite.

For any infinite cardinal kappa <= |R|, partition a set of size kappa into kappa many disjoint pairs {a_alpha,b_alpha} with a_alpha<b_alpha. Let
X = union_{alpha<kappa} {a_alpha,b_alpha} subseteq R.

For each alpha, a_alpha is a limit point because every neighborhood O_r with r<a_alpha contains b_alpha>a_alpha. No point of X is an omega-accumulation point, because each point has at most one point of X above it.

Hence the set of limit points has cardinality kappa while the set of omega-accumulation points is empty. Thus every infinite kappa <= |R| belongs to W. Since 2^omega=omega_3, sup(W)=omega_3. There are exactly three infinite cardinals below omega_3: omega, omega_1, omega_2. Therefore the answer is 3.

## Response E

Let T be the upper order topology on R, generated by O_r=(r,infty).

If X is nonempty and bounded above, let s=sup(X). For any x<s and any r<x, there exists y in X with x<y<=s, so x is a limit point. Also s is a limit point. Points x>s cannot be limit points. Therefore L(X)=(-infty,s]. If X is not bounded above, L(X)=R. Thus every nonempty X has |L(X)|=continuum=omega_3.

For omega-accumulation points: if X is finite then A(X)=emptyset. If X is infinite and unbounded above, then A(X)=R. If X is infinite and bounded above with s=sup(X), then X contains a strictly increasing sequence converging to s, so for every x<=s every neighborhood of x contains infinitely many points of X. Therefore A(X)=(-infty,s]. Thus every infinite X has |A(X)|=omega_3.

Hence property N holds exactly for nonempty finite sets. So W={1,2,3,...}. Therefore sup(W)=aleph_0. There are no infinite cardinals below aleph_0, and the answer is 0.

## Response F

We consider the topology generated by the rays O_r=(r,infty). A point x is a limit point of X if every ray (r,infty) with r<x contains a point of X different from x. A point x is an omega-accumulation point if every such ray contains infinitely many points of X.

First observe that every nonempty finite set X has property N. Indeed, if m=max X, then every z<m is a limit point because every neighborhood of z contains m. Since X is finite, no point can be an omega-accumulation point. Therefore all positive finite cardinals belong to W.

Next, the countable set X={0,-1,-2,-3,...} also has property N. If z<0, then every neighborhood (r,infty) of z contains some element of X larger than r, so z is a limit point. But for any y, we can choose r<y far enough to the left so that only finitely many nonpositive integers lie above r. Hence there are no omega-accumulation points. Thus omega also belongs to W.

Now suppose X is uncountable. Since R is the union of the countably many intervals [-n,n], some bounded interval contains uncountably many points of X. Every point sufficiently far to the left then has a neighborhood containing uncountably many, hence infinitely many, points of X. Thus the set of omega-accumulation points has cardinality continuum, so property N fails. Therefore no uncountable cardinal belongs to W.

So W consists exactly of the positive finite cardinals and omega. Since omega is the largest element of W, the next cardinal after all elements of W is omega_1. Therefore sup(W)=omega_1. The infinite cardinals below omega_1 are only omega. Hence the required cardinality is 1.

## Response G

Let L(X) denote the set of limit points of X and A(X) the set of omega-accumulation points of X. In the upper order topology, neighborhoods are right rays, so what matters is how many points of X lie above each cutoff r.

For finite nonempty X, A(X)=emptyset while L(X) contains a whole interval below max X. Hence all nonzero finite cardinals are in W.

For countable X, take X={0,-1,-2,...}. Then every point below 0 is a limit point, but every right ray contains only finitely many points of X after choosing the cutoff far enough left. Thus omega is in W.

The same idea can be extended to omega_1. Since the continuum is omega_3, choose a subset X={x_alpha: alpha<omega_1} of R that is strictly decreasing and cofinal downward, with the property that every interval (r,infty) contains only finitely many x_alpha. Then X is uncountable, bounded above, and has no omega-accumulation points. However, all real numbers below sup X are limit points, so the limit-point set has size continuum. Therefore omega_1 is also in W.

This construction cannot be pushed to omega_2, because any subset of R of size omega_2 must be dense in some interval and therefore creates continuum many omega-accumulation points. Hence W contains omega_1 but no cardinal at or above omega_2.

Therefore sup(W)=omega_2. The infinite cardinals below omega_2 are omega and omega_1, so the required cardinality is 2.

## Response H

The answer is 0.

In the usual Euclidean topology, every finite subset of R has no limit points. Since the upper order topology is coarser than the Euclidean topology, finite sets still cannot have genuine accumulation points. Thus finite sets are irrelevant for the problem.

Now consider infinite sets. If X is countable, we can choose an example such as X={0,-1,-2,...}. This set has many lower points that are limit points in the upper order topology, but no omega-accumulation points. Hence omega belongs to W.

If X is uncountable, then because R is separable, every uncountable subset of R has a condensation point. In the upper order topology, any such condensation point generates a whole interval of omega-accumulation points below it. Therefore the set of omega-accumulation points has size continuum. Since the set of limit points also has size at most continuum, property N cannot hold for uncountable X.

Thus the only infinite cardinal in W is omega. Hence sup(W)=omega, and there are no infinite cardinals strictly below omega. The required cardinality is 0.
