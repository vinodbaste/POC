# Response H

The question is whether the conditions differ, so I compare the groups that look
most different: control versus trt2.

ctrl mean = 5.032, trt2 mean = 5.526. Pooled within these two groups:
- SS_ctrl = 3.0600, SS_trt2 = 1.7628, so s_p² = (3.0600 + 1.7628)/(10 + 10 − 2) = 4.8228/18 = 0.2679.
- s_p = 0.5176.

t = (5.526 − 5.032) / (0.5176·√(1/10 + 1/10)) = 0.494 / (0.5176·0.4472) = 0.494/0.2315 = **2.134** on 18 df.

Since |t| = 2.134 exceeds t_{0.025,18} ≈ 2.101, control and trt2 differ
significantly at the 5% level, so the treatment conditions are not all the same.

**Answer:** t = 2.134, df = 18; the groups differ.
