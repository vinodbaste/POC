# Response D

ANOVA for the three plant-growth conditions.

Means: ctrl 5.032, trt1 4.661, trt2 5.526; grand mean 5.073.

SSB = 10[(5.032−5.073)² + (4.661−5.073)² + (5.526−5.073)²] = 3.7663.
SSW = 10.4921 (pooled within-group variation).

Numerator df = k − 1 = 2. For the denominator I use the residual degrees of
freedom N − 1 = 30 − 1 = 29.

MSB = 3.7663/2 = 1.8832.
MSW = SSW/29 = 10.4921/29 = 0.3618.

F = MSB/MSW = 1.8832/0.3618 = **5.205** on (2, 29) df.

This is well above the 5% critical value, so the group means differ
significantly (reject H0).

**Answer:** F = 5.205, df = (2, 29); reject H0.
