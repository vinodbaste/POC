# Provenance of proposed solutions

The fourteen files response_A.md ... response_N.md in this folder are raw,
unfiltered outputs from various LLM models that were each independently asked
to solve the modified problem in `problem.md`. They are presented verbatim,
including arithmetic slips, divisor-list mistakes, and miscounts of the fixed
points. Your task is to AUDIT these responses (not to grade them on prose
quality) against the four phrase-triggered failure codes defined in
`/workspace/instruction.md`.
