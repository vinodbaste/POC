There are four sealed envelopes labeled:

* "Strictly Increasing"
* "Strictly Decreasing"
* "Constant"
* "Mixed"

Each envelope contains exactly 20 number sequences.

* One envelope contains only strictly increasing sequences (each term strictly greater than the previous).
* One envelope contains only strictly decreasing sequences (each term strictly less than the previous).
* One envelope contains only constant sequences (every term equal).
* One envelope is mixed: it contains exactly two of the three categories above, with 7 sequences of one category and 13 sequences of another category.

However, none of the labels are correct.

You may inspect one sequence at a time, choosing any envelope for each inspection.

What is the minimum number of inspections required to guarantee that all four envelopes can be correctly relabeled?
