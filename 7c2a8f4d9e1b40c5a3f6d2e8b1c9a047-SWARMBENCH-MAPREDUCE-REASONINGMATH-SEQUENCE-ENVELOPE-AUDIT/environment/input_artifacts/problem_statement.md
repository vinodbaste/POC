Four sealed envelopes are labeled:

* "Arithmetic Sequence"
* "Geometric Sequence"
* "Constant Sequence"
* "Random"

Each envelope contains 20 number sequences.

The true contents are:

* One envelope contains only arithmetic sequences.
* One envelope contains only geometric sequences.
* One envelope contains only constant sequences.
* One envelope contains a balanced mix of exactly two of the above sequence types, with 10 sequences of each type.

However, none of the labels are correct.

You may inspect one sequence at a time, choosing any envelope for each inspection.

What is the minimum number of inspections required to guarantee that all envelopes can be correctly relabeled?
