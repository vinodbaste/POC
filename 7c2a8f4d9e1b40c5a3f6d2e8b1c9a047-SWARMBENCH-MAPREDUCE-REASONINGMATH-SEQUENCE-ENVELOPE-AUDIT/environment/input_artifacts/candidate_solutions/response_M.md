# Response M

The "Mixed" envelope is guaranteed not to be mixed.

Suppose we inspect one sequence from it and see a constant sequence.

Then:

* that envelope is the constant envelope.

Now there remain:

* increasing,
* decreasing,
* mixed.

Inspect one sequence from the envelope labeled "Constant."

If we observe:

* constant → impossible for a pure constant envelope, so it must be mixed,
* increasing → possibly pure increasing or mixed,
* decreasing → possibly pure decreasing or mixed.

In the latter cases, inspect another envelope.

Thus **3 inspections** are sufficient.
