# Response P

The mixed envelope contains exactly:

* 7 sequences of one type,
* 13 of another.

Thus if we see:

* 8 copies of the same category,

the envelope cannot be mixed anymore because the minority category would already have been exhausted.

Therefore:

* inspect the "Mixed" envelope once,
* then inspect another envelope up to 8 times.

This guarantees correctness in at most:

\[
1+8=9
\]

inspections.
