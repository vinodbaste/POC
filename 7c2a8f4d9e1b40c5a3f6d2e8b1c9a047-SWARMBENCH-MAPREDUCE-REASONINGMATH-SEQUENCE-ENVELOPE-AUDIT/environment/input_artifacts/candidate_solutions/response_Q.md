# Response Q

Start with the envelope labeled "Mixed."

Because all labels are incorrect, this envelope must be:

* increasing,
* decreasing,
* or constant.

Suppose it is decreasing.

Then inspect the envelope labeled "Strictly Decreasing."

If we observe:

* another decreasing sequence, this envelope must be mixed,
* otherwise it is pure.
