# Response F

Consider the four envelopes:

* Increasing
* Decreasing
* Constant
* Mixed

None are correctly labeled.

We inspect one sequence from each of the first three envelopes.

Suppose:

* the first is increasing,
* the second is constant,
* the third is decreasing.

Then the last envelope must be mixed.

Alternatively:

* if two envelopes produce the same category,
* then one of them must be mixed.

In every case, the correct arrangement can be deduced from these three observations.

Hence the minimum number of inspections required is:

## **3**
