Okay, let's tackle this factory problem.

So morning is 150 per hour for 8 hours = 1200 widgets. Easy enough.

Afternoon is 25 fewer per hour than morning, so 150 - 25 = 125 widgets per hour. They work 7 hours, so 125 × 7 = 875 widgets in the afternoon.

Evening is twice the afternoon rate: 2 × 125 = 250 widgets per hour. They work 4 hours so 250 × 4 = 1000.

Total: 1200 + 875 + 1000 = 3075 widgets.

Then 12% get rejected: 0.12 × 3075 = 369 widgets rejected. So 3075 - 369 = 2706 widgets pass quality control.
