# Input Provenance

The files in `/input_artifacts/proposed_solutions/response_A.md` through `response_I.md` are raw AI-generated candidate responses to the tree path-decomposition counting prompt in `/input_artifacts/problem.md`. They are unedited model outputs, preserved verbatim including verbosity, equation typos, and confident-but-wrong leaps.

They are intentionally included as heterogeneous AI outputs for a professional solution-audit workflow: incorrect uniqueness arguments that force the count to 1, a broken greedy algorithm reported as a count, a correct closed-form derivation marred by a single modular-reduction slip, a misuse of Kirchhoff's matrix-tree theorem, a truncated mid-derivation, two appeals to the wrong "double-factorial" identity, an undefined Catalan-number invocation, and a tree DP whose state transitions silently disagree with the correct count on the simplest non-trivial tree are all part of the artifact being evaluated. None of the nine proposed responses both states the gold value and accompanies it with a mathematically valid derivation, but several state intermediate values that happen to coincide with parts of the gold derivation. The responses are not answer keys; no single file contains the gold value of the count modulo the prime stated in the problem alongside a valid derivation, nor any oracle labels.

The professional task being modeled is AI output evaluation: independently solving the underlying counting problem (deriving the involution-product count over the tree implied by the parent array and reducing it modulo the prime stated in the problem), then auditing model-generated proposed solutions for concrete reasoning failures. The problem is grounded in the competition-style tree-path-counting setting referenced by the `reference_link` in `task.toml`.
