The powers of two are:

[
2,4,8,16,32,64
]

I am not including 1 because (2^0) is usually treated as the empty power and does not remove a meaningful number of stones.

Using:

[
M={2,4,8,16,32,64}
]

we get:

* 0 = P
* 1 = P
* 2 = N
* 3 = N
* 4 = N
* 5 = N

The pattern then repeats in blocks:

```text
PPNNNNPPNNNNPPNNNNPPNNNNPPNNNNPPNNNNPPNNNNPPNNNNPPNNNNPPNNNNPPNNNNPPNNNNPPNNNNPPNNNNPPNNNNPPNNN
```

So this is the classification string through 100.
