The move set contains 1, so the positions should alternate. If there is 1 stone, the next player wins by taking it. If there are 2 stones, the previous player wins because the next player is forced to give the opponent the last move.

So the pattern is simply:

[
P,N,P,N,P,N,\dots
]

Thus all even positions are P and all odd positions are N.

The required string is:

```text
PNPNPNPNPNPNPNPNPNPNPNPNPNPNPNPNPNPNPNPNPNPNPNPNPNPNPNPNPNPNPNPNPNPNPNPNPNPNPNPNPNPNPNPNPNPNPNPNPNPNP
```
