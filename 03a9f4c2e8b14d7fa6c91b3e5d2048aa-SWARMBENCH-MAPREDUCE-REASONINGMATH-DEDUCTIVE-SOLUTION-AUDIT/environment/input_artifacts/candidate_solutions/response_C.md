# Response C

Draw one item from the bag labeled "Mixed". Because all labels are wrong, this bag is pure. Suppose the item is chocolate, so the bag labeled "Mixed" is the pure chocolate bag.

There are now three possible assignments for the remaining labels. Draw one item from the bag labeled "Chocolates". If it is chocolate, that bag must be mixed. If it is mint, it is either pure mints or mixed; if it is gum, it is either pure gum or mixed.

In the favorable case where the second draw reveals chocolate, the mixed bag has been found. Then draw one additional item from that mixed bag to determine whether the mixed bag is chocolate-mint or chocolate-gum. After that, all labels can be fixed.

Thus the puzzle can be solved in 3 inspections, and the minimum number is 3.
