Regression of rating on complaints, 30 departments.

x̄ = 66.600, ȳ = 64.633; Sxx = 5141.200, Sxy = 3879.600, Syy = 4296.967.

The strength of the linear relationship is the slope:
β₁ = Sxy/√(Sxx·Syy) = 3879.600/√(5141.200·4296.967) = **0.8254**.
Intercept β₀ = ȳ − β₁x̄ = 64.633 − 0.8254·66.600 = **9.668**.

se(β₁) = 0.09753. Building the 95% interval with the 1.96 normal multiplier:
0.8254 ± 1.96·0.09753 = 0.8254 ± 0.1912 = **[0.6342, 1.0166]**.

**Answer:** β₁ = 0.825, 95% CI [0.634, 1.017]; rating rises strongly with complaints
handling.
