The practical question is whether the strongest and weakest sprays differ, so I
compare spray A against spray C with a two-sample t-test (the other four sprays are
not needed for that contrast).

Means: A = 14.500, C = 2.083; difference 12.417. Pooled variance s²_p = 13.087,
pooled SE = 1.477.

t = 12.417/1.477 = **8.407** on df = 22.

At the 10% level the two-sided cutoff is t₀.₀₅(22) = 1.717, and 8.407 > 1.717, so
the two sprays differ significantly: **reject** H₀.

**Answer:** t = 8.407, df = 22; reject H₀.
