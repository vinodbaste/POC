# Response A

One-way ANOVA on all 72 units, six sprays of twelve (A, B, C, D, E, F).

Group means: A = 14.500, B = 15.333, C = 2.083, D = 4.917, E = 3.500,
F = 16.667; grand mean = 9.500.

Between-group sum of squares:
SSB = 12·Σ_g (ȳ_g − 9.5)² = 2668.833.
Within-group sum of squares: SSW = Σ_g Σ_i (y − ȳ_g)² = 1015.167.

Degrees of freedom: df_between = k−1 = 5, df_within = N−k = 66.
Mean squares: MSB = 2668.833/5 = 533.767, MSW = 1015.167/66 = 15.381.

F = MSB/MSW = 533.767/15.381 = **34.702** on (5, 66) df.

The 5% critical value F(5, 66) = 2.35; since 34.702 > 2.35, I **reject** H₀ of equal
spray means.

**Answer:** F = 34.702, df = (5, 66); reject H₀ at α = 0.05.
