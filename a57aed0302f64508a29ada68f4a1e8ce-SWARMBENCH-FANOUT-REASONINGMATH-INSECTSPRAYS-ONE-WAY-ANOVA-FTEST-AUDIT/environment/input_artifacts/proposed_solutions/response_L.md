To see whether the sprays matter I take the two that look most different in the
table, spray B and spray D, and run a two-sample t-test on them; the remaining
sprays are set aside for this comparison.

Means: B = 15.333, D = 4.917; difference 10.417. Pooled variance s²_p = 12.254,
pooled SE = 1.429.

t = 10.417/1.429 = **7.289** on df = 22.

At α = 0.05 the two-sided critical value is t₀.₀₂₅(22) = 2.074. Since 7.289 > 2.074,
the two sprays differ significantly, so I **reject** H₀.

**Answer:** t = 7.289, df = 22; reject H₀ at α = 0.05.
