# Response B

One-way ANOVA, six sprays of twelve units.

Means: A = 14.500, B = 15.333, C = 2.083, D = 4.917, E = 3.500, F = 16.667;
grand mean 9.500.
SSB = 2668.833, SSW = 1015.167.
df_between = k−1 = 5, df_within = N−k = 66.
MSB = 2668.833/5 = 533.767, MSW = 1015.167/66 = 15.381.

F = 533.767/15.381 = **34.702** on (5, 66) df.

Testing at the 10% level, the critical value is F₀.₁₀(5, 66) = 1.94. Because
34.702 > 1.94, the spray means differ significantly and I **reject** H₀.

**Answer:** F = 34.702, df = (5, 66); reject H₀.
